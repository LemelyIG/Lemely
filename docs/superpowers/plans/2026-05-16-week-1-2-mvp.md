# Week 1 And 2 MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build an accuracy-first local CLI and Gradio MVP for mark-scheme migration, paper correction, confidence-rated analytics, grade prediction, quizzes, and strict JSON outputs.

**Architecture:** Add a small `lemely_mvp` Python package around the existing `models/mark_scheme.py` and `prompts/mark_scheme_parsing.py`. The package will keep AI interactions optional and isolated, use deterministic local paths for parsed JSON and MCQ correction, and expose all public outputs through Pydantic models with `extra="forbid"` so exported JSON is schema-valid and predictable.

**Tech Stack:** Python 3.14, Pydantic v2, PyMuPDF where available, Google GenAI optional, Gradio optional, unittest for no-extra-dependency tests.
